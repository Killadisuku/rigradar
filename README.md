# RigRadar

Waze-style navigation built for truck drivers.

Truck-legal routing, live community reports, diesel and parking, weigh stations, and hours-of-service clocks — from a night-highway cab HUD.

## Features

- Turn-by-turn navigation with voice guidance
- Truck profile: height, weight, length, axles, hazmat
- Avoided low bridges and weight-restricted roads
- Community reports (police, crash, hazard, work zone, camera)
- Truck stops with diesel, DEF, and parking availability
- Weigh station open/closed
- Hours of service (11 / 14 / 70 + 30-minute break)
- Nearby fleet overlay and night map

Demo GPS starts on the I-35E & I-20 corridor in Dallas.

## Stack

React 19, TanStack Start, Tailwind v4, Leaflet, Zustand.
